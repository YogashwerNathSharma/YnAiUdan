# YnAiUdan

YnAiUdan is a production-grade, modular AI agent platform designed for ChatGPT-style conversation, coding, GitHub workflows, web research, multimodal generation, documents, memory, and controlled autonomous execution.

## Independence

YnAiUdan is a completely independent project. It does not use, import, modify, or depend on the existing ERP repositories, databases, routes, environment variables, or infrastructure.

## Phase 1

Phase 1 establishes the production foundation:

- React + TypeScript frontend
- Node.js + TypeScript API
- versioned API architecture
- provider abstraction
- conversation/project/task foundations
- security-first configuration
- testing and CI foundation

## Development rules

1. Inspect the latest `main` before changes.
2. Preserve existing work.
3. Never force-push or reset shared history.
4. Never commit secrets.
5. Verify builds/tests before declaring work complete.
6. High-risk external actions remain permission-controlled.
